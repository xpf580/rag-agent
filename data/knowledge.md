# 金融量化知识库

## 1. 量化交易概览

量化交易是使用数据、统计方法、数学模型和程序化规则来发现和执行交易机会。它通常包括数据获取、特征工程、策略开发、回测、风险控制和执行。量化研究通常关注收益、风险、稳定性和可复制性，而不是仅靠主观判断。

核心目标：
- 产生可持续的 alpha
- 控制最大回撤
- 管理交易成本与滑点
- 保证策略在不同市场环境下可用

## 2. 量化研究的基本流程

1. 数据采集：价格、成交量、订单簿、财务指标、宏观指标、新闻情绪。
2. 数据清洗：去重、对齐、补缺失值、处理停盘、修正错误数据。
3. 因子构造：动量、价值、质量、波动、流动性、事件驱动因子。
4. 模型开发：线性模型、树模型、时间序列模型、深度学习模型。
5. 回测：真实交易规则、重放、交易成本模拟、风控约束。
6. 验证：样本内外、滚动验证、交叉验证、稳健性分析。
7. 上线管理：交易执行、仓位控制、风控、监控和复盘。

## 3. 交易数据类型

### 3.1 市场数据
- OHLCV：开盘价、高点、低点、收盘价、成交量
- Tick 数据：逐笔成交数据
- 订单簿数据：买卖挂单量、价格深度
- 期货和期权数据：合约乘数、到期日、隐含波动率

### 3.2 基础面数据
- 财务报表：利润表、现金流量表、资产负债表
- 估值指标：PE、PB、EV/EBITDA、ROE、ROIC
- 宏观数据：利率、通胀、GDP、制造业 PMI、失业率

### 3.3 事件数据
- 财报发布、利率会议、政策变动、行业新闻、舆情

### 3.4 另类数据
- 社交媒体、供应链、卫星数据、信用债数据、订单流数据

## 4. 常见因子

### 4.1 动量因子
动量因子关注过去一段时间的价格趋势。典型策略包括：过去 1 个月、3 个月、6 个月、12 个月收益率排序。

特点：
- 在趋势市场中有效
- 可能在反转市场中失效
- 需考虑交易成本和回撤控制

### 4.2 价值因子
价值因子通常使用估值指标，例如：
- PB（市净率）
- PE（市盈率）
- EV/EBITDA
- 账面市值比

低估值股票往往具有更高的长期回报，但可能伴随价值陷阱。

### 4.3 质量因子
用于衡量公司质量，包括：
- ROE
- ROIC
- 营业利润率
- 自由现金流
- 负债率

### 4.4 波动率因子
- 低波动率策略
- 高波动率策略
- 波动率套利

### 4.5 流动性因子
- 成交额比
- 换手率
- Amihud illiquidity
- 市场深度

### 4.6 事件驱动因子
- 财报超预期
- 分红/回购
- IPO 事件
- 政策驱动事件

## 5. Alpha 与 Beta

- Beta：对市场风险的暴露，通常与市场指数相关。
- Alpha：在扣除市场风险和其他系统性风险后，策略的超额收益。

量化策略通常关注：
- 通过因子构建 alpha
- 用风险模型控制 beta 和行业暴露
- 通过仓位控制提升风险调整后收益

## 6. 风险管理

风险管理是量化交易成功的核心。常见的风险控制方法包括：

### 6.1 最大回撤
最大回撤衡量账户从峰值到谷底的跌幅。量化策略需要控制单策略和组合层面的回撤。

### 6.2 Sharpe Ratio
Sharpe 比率 = 预期收益 / 波动率。用于衡量风险调整后收益。

### 6.3 Sortino Ratio
Sortino 比率只关注下行波动，通常更适合衡量非对称收益风险。

### 6.4 VaR 与 CVaR
- VaR：在置信水平下的潜在损失
- CVaR：尾部风险，更关注极端损失

### 6.5 头寸规模与仓位控制
- 不能让单个因子或单一资产过度集中
- 通过分层、限制、止损和动态仓位控制来降低崩盘风险

### 6.6 杠杆与融资成本
- 杠杆会放大收益和损失
- 量化策略需要考虑融资成本、保证金要求和强制平仓风险

## 7. 回测的重要原则

回测并不是“跑出一个高收益数值”就足够。高质量回测需要满足：

- 数据为真实历史数据，不应使用未来函数
- 交易成本必须被计入
- 交易滑点要模拟
- 不能出现数据泄漏
- 避免过拟合
- 检查样本外表现
- 验证不同市场阶段的稳定性

### 7.1 过拟合风险
在量化研究中，过拟合非常常见。常见表现：
- 在样本内表现极好，而样本外表现很差
- 因子崩盘时失效
- 选股规则过于复杂并无理论支撑

### 7.2 交叉验证
常见方法：
- 时间序列交叉验证
- 滚动窗口验证
- 分段回测（牛市/熊市/震荡市）

## 8. 交易成本与执行

### 8.1 交易成本
交易成本包括：
- 佣金
- 印花税
- 滑点
- 市场冲击成本
- 资金成本

### 8.2 执行算法
常见执行方式：
- VWAP：按成交量加权平均价格
- TWAP：时间加权平均价格
- POV：按市场参与度执行
- Iceberg order：隐匿大单

在量化交易中，策略收益最终必须扣除执行成本，否则看起来很强，但实际很难落地。

## 9. 机器学习在量化中的应用

量化研究中常见机器学习方法：
- 线性回归
- 随机森林
- XGBoost、LightGBM
- CatBoost
- LSTM、Transformer 时间序列模型
- 图神经网络（用于关系网络）

常见任务：
- 预测收益率
- 预测波动率
- 估计风险暴露
- 分类牛熊状态
- 识别异常事件

注意：机器学习不等于更高收益。复杂模型可能带来更高噪声和更差的稳定性。更重要的是数据质量、特征工程和防止过拟合。

## 10. 量化策略类型

### 10.1 统计套利
基于协整关系、均值回归和因子收益。常见于高频和中频策略。

### 10.2 多因子策略
将多个因子组合成一个评分系统，例如：
- 动量 + 质量 + 价值
- 低波 + 高质量 + 低估值

### 10.3 事件驱动策略
围绕财报、并购、政策和行业变化构建择时与选股模型。

### 10.4 高频交易
利用微观结构、成交速度和订单簿信息进行极短周期交易。通常要求低延迟、低滑点、高稳定主机环境。

### 10.5 CTA / 商品趋势策略
关注商品、外汇和利率市场中的趋势和反趋势机会。

## 11. 量化研究中的关键指标

- 年化收益率
- 波动率
- 最大回撤
- Sharpe Ratio
- Sortino Ratio
- Calmar Ratio
- 交易次数
- 命中率
- 期望收益 / 每笔交易
- 资本利用率

## 12. 量化策略的落地要求

策略并非只要回测好就能上线。真正可以落地的策略通常还需要：

- 数据可得性：有稳定的数据源
- 执行可行性：能够在真实市场中下单
- 成本可控：交易和融资成本可接受
- 稳定性：不同市场周期表现一致
- 风控：支持止损、限仓、停盘机制
- 监控：实时监控回撤和异常交易

## 13. 常见商业数据源

- Alpha Vantage：宏观和股票数据 API
- Yahoo Finance：免费公开市场数据
- FRED：宏观经济数据
- Quandl：金融数据
- Polygon：股票和加密货币数据
- Wind / CSMAR / Choice / iFind：国内专业数据源
- Bloomberg / Refinitiv：机构级高质量金融数据
- SEC EDGAR：美国公司财报数据

## 14. 量化系统工程

量化策略的工程基础包括：
- 数据平台：缓存、存储、版本控制
- 回测框架：因子计算、回测脚本、结果统计
- 风控系统：单票限制、组合限制、停盘机制
- 执行模块：模拟交易和实盘交易
- 报告系统：每日收益、风险、异常统计

## 15. 实战建议

如果你正在入门金融量化，建议按这个顺序来：

1. 学会 Python 和 pandas/numpy
2. 学会回测和基本统计概念
3. 学会读取 OHLCV 数据
4. 先做简单的动量和均值回归策略
5. 引入风险管理
6. 改善交易成本处理
7. 做多因子研究和稳健性分析
8. 最后做策略落地和风险控制

### 15.1 入门策略示例
- 低估值+质量筛选
- 动量择时
- 反转策略
- 多空配对策略
- 事件驱动模型

### 15.2 实战注意事项
- 不要因为一段时间高收益就相信策略
- 不要忽略数据泄漏
- 不要在没有成本的前提下评估策略
- 不要在样本内过度优化
- 不要用复杂模型掩盖基础逻辑问题

## 16. 量化交易的本质

量化交易的核心不只是“预测”，而是：
- 识别真实的可重复风险收益来源
- 用数据和数学模型验证
- 控制风险和成本
- 把洞察变成稳定的交易规则

真正优秀的量化研究通常来自：
- 对市场微观结构的理解
- 对因子稳定性的识别
- 对数据质量和成本的尊重
- 对风险和执行的重视

## 17. 100MB 以上知识库的真实来源建议

如果你希望这个项目真正拥有“大知识库”，推荐从以下来源积累：

1. SEC EDGAR 财报数据：美国上市公司财报、年报、10-K、10-Q
2. FRED 宏观数据：利率、GDP、CPI、失业率、制造业指标
3. Alpha Vantage / Polygon / Yahoo Finance：历史行情数据
4. 研究报告和金融论文：arXiv、SSRN、企业研究报告
5. 新闻、公告、政策文本：财报公告、央行公告、上市公司新闻稿
6. 订单簿和微观结构数据：交易所公开数据、券商研究报告

实际做法：
- 先收集多个 CSV / JSON / TXT / PDF 文档
- 按章节或页面切 chunk
- 用 embedding 建库
- 取 topK=5~20 文档进行最终问答

对于 100MB 级知识库，推荐存成多文件目录结构，而不是单个 knowledge.md 文件。这样更适合知识分块、增量更新和版本管理。

## 18. 一个现实可用的知识库结构

```text
knowledge/
  macro/
    fed_policy.txt
    inflation.md
  stocks/
    factor_basics.md
    earnings_guide.md
  strategies/
    momentum_strategy.md
    risk_parity.md
  research/
    quant_papers/
```

这样做的好处：
- 更容易按主题检索
- 更容易做 chunking
- 更容易更新和维护
- 更适合大规模 RAG 训练与问答

## 19. 总结

金融量化知识库的重点不是“堆很多字”，而是：
- 数据完整
- 因子合理
- 风控充分
- 回测严谨
- 执行可落地

如果你要把这个项目做成真正的金融量化智能助手，建议把知识库从 demo 的小文本升级成：
- 财报/行情/宏观/因子/策略
- 多个主题目录
- 100MB 级文本或 PDF 语料
- 结合大模型和检索增强生成

在实际生产中，最常见的方案是：
- 按主题构建知识库
- 结构化存储
- 分块嵌入
- topK 检索
- 重排和 prompt 组装
