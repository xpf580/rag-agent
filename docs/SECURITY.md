# Security

## 当前必须遵守的规则

- `.env` 不得提交；API Key 只通过环境变量注入。
- 本项目当前 `.env` 曾包含明文密钥，应该立即在服务商侧撤销并轮换。
- 只加载本地可信来源的 FAISS 索引；`allow_dangerous_deserialization` 不能
  用于不可信文件。
- MCP 工具只允许访问配置的知识库目录，不暴露任意文件系统读写。
- 生产环境必须给 MCP/HTTP 入口增加认证、审计日志和请求限流。

## 威胁模型

主要风险包括：

1. Prompt Injection：知识库文档中包含诱导模型越权的指令。
2. 数据外泄：模型请求中携带敏感文档上下文。
3. 工具越权：MCP 客户端调用超出预期的工具能力。
4. 供应链风险：FAISS pickle、第三方模型和外部 MCP Server。

建议在生产环境增加文档清洗、敏感信息脱敏、租户隔离、工具白名单和依赖
漏洞扫描。
