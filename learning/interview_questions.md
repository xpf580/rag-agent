# 面试题与项目表达

## 项目介绍模板（5 分钟）

这是一个面向本地 Markdown/TXT 知识库的混合 RAG 问答服务。系统先对文档做标题感知
切分，使用本地 Embedding 建立持久化 FAISS 索引；查询阶段同时走向量检索和词法检索，
再用 RRF 融合排名。LangGraph 编排输入校验、检索和生成节点，回答返回来源章节和
chunk id。系统提供 Streamlit、FastAPI 和 MCP 三种接入方式，并通过内容 manifest
自动判断索引是否需要重建。

## 高频问题

1. **为什么使用 RAG 而不是只靠模型？**
   - RAG 将可更新、可追溯的外部知识注入模型，适合私有知识和频繁更新内容。
2. **为什么不能只用向量检索？**
   - 向量检索擅长语义相似，但可能弱化专有名词、缩写、数字和精确指标；词法检索可以补足。
3. **BM25 和 Embedding 的区别？**
   - BM25 基于词项频率和逆文档频率；Embedding 基于语义向量空间。
4. **RRF 为什么按排名融合？**
   - 不同检索器的原始分数尺度不可直接比较，排名融合更稳定，代价是丢失部分原始分数信息。
5. **Chunk 如何选择？**
   - 以语义完整性为第一目标，再通过 chunk size、overlap 和评测集调参。
6. **LangChain 和 LangGraph 的边界？**
   - LangChain 提供模型、Prompt、Document、Retriever 等组件；LangGraph 管理有状态、多节点、可恢复的流程。
7. **MCP 是什么？**
   - MCP 是连接 Agent 与外部工具/资源的协议，不等同于 RAG，也不替代权限控制。
8. **如何评测 RAG？**
   - 检索看 Recall@K、MRR、nDCG；生成看 relevance、faithfulness、citation accuracy。
9. **如何降低幻觉？**
   - 提高召回质量、限制上下文来源、要求引用、允许拒答，并用评测集做回归测试。
10. **如何处理索引更新？**
    - 对源文档和切分配置计算 manifest；不一致时重建，生产系统可升级为增量索引。
11. **如何处理模型不可用？**
    - 超时、有限重试、明确错误和本地检索降级；不能假装生成了可靠答案。
12. **如何保证 MCP 安全？**
    - 工具白名单、参数校验、目录沙箱、认证、审计和限流；不把任意 shell 暴露给模型。
13. **如何降低延迟？**
    - 缓存 Embedding/索引、限制候选数、并行召回、控制上下文、选择合适模型。
14. **如何降低成本？**
    - 先用本地检索过滤，再把小上下文交给模型；缓存重复问题，区分轻量和高质量模型。
15. **如何扩展多轮对话？**
    - 将历史消息和检索查询分开，增加 query rewrite 和 LangGraph checkpoint。
16. **如何处理知识库外问题？**
    - 使用相似度/关键词阈值，返回明确拒答，而不是把不相关上下文交给模型。
17. **FAISS 适合生产吗？**
    - 适合单机和中小规模本地检索；需要多租户、远程服务或高可用时考虑 Qdrant、pgvector、OpenSearch。
18. **如何防止 Prompt Injection？**
    - 文档内容视为不可信数据，系统指令与文档隔离，工具权限在服务端强制执行。
19. **为什么要返回 metadata？**
    - 用于引用、调试、评测、审计和后续删除/更新文档。
20. **这个项目下一步是什么？**
    - Reranker、评测回归、Tracing、Checkpoint、多轮对话和生产 API。

## 面试现场演示顺序

1. 展示 `data/knowledge.md`；
2. 运行一次 `/query` 或 Streamlit 问答；
3. 展示 sources；
4. 切换 dense/lexical/hybrid 评测；
5. 解释 LangGraph 状态；
6. 展示 MCP 工具；
7. 说明失败降级和安全边界。
